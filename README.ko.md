# Velora 0.5.0

## 배경·장식·곡선·폰트

편집기 왼쪽 ✦ **배경과 장식**에서 선형·방사형 그라데이션 12종과 물결·점선 궤도·별·소프트 글로우·도트·컬러 리본·크로스·동심원 8종을 추가합니다. 배경은 캔버스 크기의 독립 레이어로 가장 뒤에 배치합니다. 배경을 다시 선택하면 같은 배경 레이어의 색상을 바꿉니다. 오른쪽 **채우기**에서 2~8개 색상 포인트, 위치와 각도를 편집할 수 있습니다.

곡선 레이어를 선택하면 **곡선 조절**에서 시작점·두 조절점·끝점의 X/Y 값을 수정합니다. **라인 스타일**은 실선·대시·도트, 점선 길이·간격과 선 끝 모양을 제공합니다. 텍스트에는 기울임·밑줄·취소선을 적용할 수 있습니다.

왼쪽 **TTF 폰트 관리** 또는 **타이포그래피 → TTF 폰트 가져오기**에서 `.ttf`를 선택하거나 드롭합니다. 선택한 글자에 적용하며, 선택한 텍스트가 없으면 새 글자를 만듭니다. 폰트 데이터는 프로젝트와 로컬 작업 공간에 저장되어 재시작·파일 이동 후에도 사용할 수 있습니다. 파일당 5MB, 프로젝트당 12개·합계 12MB를 지원합니다.

PNG·GIF·SVG 내보내기에서는 가져온 폰트를 벡터 경로로 계산하고 HTML·React에는 폰트 데이터를 CSS에 포함합니다. Android·WPF·PPTX 대상에서는 해당 폰트를 별도로 등록해야 하며 일부 그라데이션·점선·글자 효과는 대상 형식에서 근사됩니다. 가져온 폰트의 배포 조건은 폰트별로 확인하세요.

## GIF 만들기

레이어의 **모션**에서 프리셋이나 키프레임을 설정한 다음 왼쪽 **GIF** 또는 **내보내기 → GIF 애니메이션**을 누릅니다. 출력 너비, 길이, FPS, 반복 여부와 투명 영역에 사용할 배경색을 정하고 **GIF 만들기**를 누릅니다. 생성 후 미리보기에서 확인하고 **GIF 저장**을 누릅니다. 진행률과 중지 버튼을 제공합니다.

GIF는 현재 아트보드의 타임라인 움직임을 렌더링합니다. 출력은 변당 최대 2,048px, 0.2~20초, 5~30FPS, 최대 300프레임이며 전체 처리량이 큰 조합은 만들기 전에 안내합니다. GIF의 256색 팔레트를 사용하고 디더링으로 그라데이션 밴딩을 줄입니다. 투명 영역은 선택한 배경색으로 합성합니다. 클릭·화면 전환 프로토타입은 포함하지 않습니다.

## 첨부 스타일의 배너 시작하기

**새 디자인 만들기 → Aurora · 소프트 Discord 배너**를 선택합니다. 2048×683 크기의 하늘·라일락 그라데이션, 가는 곡선, 점선 궤도, 캘리그래피와 작은 장식을 편집할 수 있습니다. 제목은 Windows의 Segoe Script를 기본으로 사용하며 원하는 TTF로 바꿀 수 있습니다. 별과 작은 점에는 모션 프리셋이 있어 바로 GIF로 만들어 볼 수 있습니다.

## 자유 사이즈와 디자인 예시

홈의 **새 디자인 만들기** 또는 편집기의 **새 아트보드 (+)**를 누르면 상단에 **자유 사이즈**가 나옵니다. 작업 이름과 종류를 정하고 원하는 너비·높이를 입력한 뒤 **만들기**를 누릅니다. 지원 범위는 각 변 1~16,384px이며 소수 입력도 가능합니다. 가운데 ↔ 버튼으로 가로·세로를 교환합니다.

기존 작업의 크기는 선택을 해제한 뒤 오른쪽 **아트보드 → 자유 사이즈**에서 입력하고 **크기 적용**을 누릅니다. 두 값이 한 번에 적용되며 Ctrl+Z로 되돌릴 수 있습니다. 화면 안의 레이어는 배율로 일괄 확대하지 않고 설정된 제약에 따라 위치·크기를 조정합니다.

예시 디자인은 총 24개입니다. Windows 작업 보드·음악, Android 여행·쇼핑, 웹 포트폴리오·분석 대시보드, 정사각형·스토리·와이드 배너, 제품 소개·성과·로드맵 슬라이드 등 예시와 Aurora 소프트 배너를 제공합니다. 모든 예시는 텍스트와 도형을 수정할 수 있습니다. 새 예시는 갤러리에서 선택해 추가하며 기존 로컬 프로젝트는 그대로 유지합니다.

Windows용 로컬 디자인 편집기입니다. 검은 유리 질감, 은은한 은색 테두리와 둥근 컨트롤로 홈·편집기·타임라인·대화상자를 구성했습니다. Windows, Android, 웹, 배너, 프레젠테이션을 디자인하고 코드와 이미지로 내보냅니다. AI 클라이언트가 열린 문서를 읽고 편집하는 실제 MCP 서버를 포함합니다.

## 작업 공간 홈

앱을 열면 프로젝트 썸네일이 있는 홈이 나타납니다. 카드를 눌러 수정하고 편집기 왼쪽 위의 집 모양 버튼으로 홈에 돌아옵니다. 새 디자인을 만들거나 `.luma.json` 파일을 가져와 각각의 프로젝트로 보관할 수 있습니다.

검색, 플랫폼 필터, 이름·작업 날짜 정렬, 그리드·목록 보기, 즐겨찾기, 이름 변경, 복제와 휴지통·복원을 제공합니다. 프로젝트들은 이 PC의 IndexedDB에 따로 저장합니다. 휴지통 이동은 영구 삭제하지 않습니다. 프로젝트를 바꾸면 MCP의 revision도 바뀌어 이전 문서에 대한 오래된 변경을 차단합니다.

0.2에서 마지막으로 열었던 자동 저장 문서는 첫 프로젝트로 가져오며 기존 데이터를 지우지 않습니다. 새로운 Obsidian 유리 UI 예제와 Android·웹·배너·프레젠테이션 예제를 함께 제공합니다. 클라우드 동기화나 여러 PC 사이의 파일 공유는 포함하지 않습니다. `.luma.json` 파일로 별도 보관하고 옮길 수 있습니다.

## 설치와 시작

`Velora-Setup-0.5.0.exe`를 실행합니다. 현재 Windows 사용자 계정에 설치하며 바탕화면과 시작 메뉴에 **Velora** 바로가기를 만듭니다. 설치 파일에는 상용 코드 서명이 없습니다. 첫 홈에는 기존 문서와 새 디자인 예제의 카드가 나타납니다.

프로젝트는 로컬에 자동 저장됩니다. `Ctrl+S`로 `.luma.json` 파일을 따로 저장하고 `Ctrl+O`로 다시 엽니다. 0.1의 자동 저장 데이터는 별도로 보존하며 도움말의 복원 버튼으로 불러올 수 있습니다. 0.2 문서를 0.1 편집기로 여는 것은 지원하지 않습니다.

- 오른쪽: 위치·크기, 각 모서리, 그라디언트·선·그림자·블러·유리 효과, 글꼴·행간·자간, 부모와 제약, 자동 레이아웃.

- 구조: 중첩 프레임·그룹, 가로·세로 자동 레이아웃, gap·padding·정렬, fixed·fill·hug 크기, 부모 크기 변경 제약, 정렬·분배·순서 변경.

## 프로토타입과 모션

상단 **프로토타입**에서 클릭·호버 트리거와 페이지 이동·오버레이 열기·닫기를 설정합니다. **미리보기**에서 연결과 전환을 실행합니다. 기본 Windows 예제의 새 프로젝트 버튼은 유리 모달을 엽니다.

**모션**에서는 타임라인, 재생·일시정지, 재생 헤드, 요소별 키프레임과 이징을 편집합니다. 위치, 회전, 크기 배율과 투명도를 시간에 따라 바꿀 수 있습니다. 간단한 등장·플로팅 등의 프리셋도 제공합니다.

## 내보내기

- **HTML/CSS**: 모든 페이지와 런타임을 함께 내보냅니다. 중첩 구조·flex 레이아웃·스타일·모션·페이지 연결과 모달 상호작용을 포함합니다.
- **React**: JSX 화면과 스타일을 만듭니다. 앱의 라우터 및 상태 연결은 사용 중인 프로젝트에서 구성합니다.
- **Android XML / Jetpack Compose**: Android UI 코드와 필요한 drawable 등 보조 파일을 만듭니다. Android Studio에서 사용하는 의존성 및 앱 구조에 통합합니다.
- **Windows XAML**: WPF 화면, C#과 .NET 10 Windows 프로젝트를 생성합니다. .NET 10 SDK를 설치한 Windows에서 `dotnet build`로 빌드합니다.
- **SVG / PNG**: 현재 화면을 저장합니다. PNG는 최대 2배, 3,200만 픽셀로 제한합니다.
- **PPTX**: 모든 아트보드를 16:9 슬라이드에 비율을 유지해 배치합니다. 기본 텍스트와 도형을 편집 가능한 요소로 변환합니다.
- **JSON**: 문서의 구조와 편집 설정을 보관합니다.

코드 탭에서 파일별 내용을 확인·복사하고 **폴더로 내보내기**로 저장합니다. 웹 결과는 앱 안에서 미리 볼 수 있습니다. 내보내기 화면의 변환 메모도 확인하세요. Android와 WPF는 일부 계층을 평탄화하고 웹 유리 효과를 근사합니다. 네이티브 코드 및 PPTX에는 사용자 지정 키프레임이나 모든 상호작용이 동일하게 반영되지 않습니다. 이미지 리소스와 대상 환경별 구성은 추가 작업이 필요할 수 있습니다. 비즈니스 로직과 서버 연결은 디자인 코드에 포함하지 않습니다.

## MCP와 AI 편집

앱의 **AI Bridge**에서 연결을 켜고 GPT Codex, Antigravity, Claude Desktop, Claude Code용 설정을 복사합니다. 설치된 앱 자체의 런타임으로 서버를 실행하므로 사용자는 별도 Node.js를 설치할 필요가 없습니다. Velora 편집 창이 열려 있어야 문서 호출이 동작합니다.

문서·요소 읽기, 템플릿 조회, 아트보드 생성, 원자적 배치 편집, 선택, 실행 취소·다시 실행, 코드 생성, PNG 렌더링, 확대 조절의 11개 도구와 문서 리소스·작업 프롬프트를 제공합니다. UI의 읽기 전용 옵션으로 문서 변경을 차단할 수 있습니다. AI의 변경도 실행 취소 기록에 들어갑니다. revision 검사로 동시에 바뀐 문서에 대한 오래된 변경을 거부합니다.

자세한 연결은 [MCP 안내](docs/MCP.ko.md), 도구 사용은 [편집 예제](docs/MCP-operations.ko.md)를 참고하세요. 브리지는 인증된 로컬 연결을 사용합니다. 요청한 디자인 데이터와 이미지는 사용자가 연결한 AI 클라이언트로 전달됩니다. 클라이언트의 모델 계정이나 구독은 Velora에 포함되지 않습니다.

## 단축키

`V` 선택, `H` 이동, `F` 프레임, `T` 텍스트, `O` 타원, `L` 선, `P` 자유 그리기. Space를 누른 채 드래그하면 캔버스를 이동합니다. Ctrl+휠은 확대·축소, 일반 휠은 이동입니다.

`Ctrl+G` 그룹, `Ctrl+Shift+G` 해제, `Ctrl+Alt+K` 컴포넌트, `Ctrl+D` 복제, `Ctrl+Z` 취소, `Ctrl+Y` 또는 `Ctrl+Shift+Z` 다시 실행, `Ctrl+C/V/X` 복사·붙여넣기·잘라내기, 방향키 1px 이동, Shift+방향키 10px 이동, Delete 삭제. `Alt+Enter` 프로토타입, `Ctrl+K` 명령 검색, `?` 도움말.

## 개발과 검증

Windows와 Node.js 22.12 이상을 사용합니다. 의존성과 Electron을 내려받는 첫 빌드에는 인터넷 연결이 필요합니다.

```powershell
npm ci --no-audit --no-fund
node node_modules/electron/install.js
npm run dist
```

같은 작업을 `build-windows.cmd`로 실행할 수 있습니다. 설치 파일은 소스 폴더 옆 `release`에 생성됩니다. `npm run dev`로 웹 개발 서버를 켜고, 별도 창에서 아래 명령으로 데스크톱 개발 창을 엽니다.

```powershell
$env:LUMA_DEV_URL = 'http://127.0.0.1:5173'
npm start
```

`npm test`는 문서 편집·레이아웃·컴포넌트·내보내기·검증 테스트를, `node --test mcp/check-integration.cjs`는 공식 MCP 클라이언트 초기화와 전송·보안·재연결을 검사합니다. 설치판 UI 자동화와 생성된 WPF 프로젝트의 실제 빌드도 별도로 확인했습니다. Android SDK를 통한 네이티브 컴파일은 확인하지 않았습니다.

## 지원 범위

0.4는 단일 사용자용 디자인 편집기입니다. Figma 전체 기능이나 `.fig` 파일 호환, 실시간 공동 편집, 펜 도구의 정밀 베지어 핸들, 모든 언어 변환, 물리 기반 리퀴드 글래스는 제공하지 않습니다. 유리 효과는 블러·투명도·그라디언트의 시각적 합성입니다.

프로젝트 최대 30MB, 100개 아트보드, 아트보드당 1,000개 요소, 화면·요소 크기 최대 16,384px입니다. 코드 파일 최대 30MB, 코드 묶음 2,500개·전체 60MB, 바이너리 출력 80MB를 지원합니다. MCP 한 요청은 최대 2MB, 배치당 100개 작업입니다. 큰 화면의 렌더링과 내보내기는 컴퓨터 성능과 대상 형식의 제약을 받습니다.


## Velora 이름 변경

0.4부터 앱 이름과 로고를 Velora로 바꿨습니다. 이전 프로젝트·자동 저장·즐겨찾기와 휴지통을 이어 쓰도록 내부 프로필 및 MCP 도구 이름을 유지합니다. `.luma.json` 파일도 계속 지원합니다. 실행 파일이 Velora.exe로 바뀌므로 AI Bridge에서 새 MCP 설정을 복사합니다.
